# 주유소 데이터 도구

Windows 파일 탐색기에서 `offline.html`을 더블클릭하거나 `start.bat`을 실행하세요. 최신 Edge 또는 Chrome에서 열리며 인터넷, Python, 로컬 서버 없이 실행됩니다. 기본 CSV와 지도 경계가 HTML 파일에 포함되어 있습니다.

- **지역별 CSV 추출**에서 위치 CSV와 판매가격 CSV를 업로드하고 시도 및 시·군·구를 선택하세요. 두 저장 버튼으로 각각 내려받을 수 있습니다.
- **주유소 지도·가격 조회**에서 원본 CSV 두 개 또는 방금 저장한 CSV 두 개를 업로드하세요. 지역을 고른 뒤 지도 마커나 목록의 주유소를 선택하고 관측일을 변경할 수 있습니다.
- 두 메뉴의 **기본 CSV 불러오기** 버튼으로 `전국주유소표준데이터` 폴더에 포함된 원본 CSV 두 개를 바로 불러올 수 있습니다.
- CSV는 브라우저에서 처리합니다. 기본 데이터나 코드를 수정한 다음 배포 파일을 갱신하려면 Python 3에서 `python -B build_offline.py`를 실행하세요. 개발용 로컬 서버는 `python serve.py`로 실행합니다.
